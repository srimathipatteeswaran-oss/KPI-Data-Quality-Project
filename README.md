KPI Dictionary & Data Quality Project

Project Overview

This project is part of my Data Analytics & Business Intelligence internship at RabTech Academy.

The objective is to define measurable business KPIs and establish data quality rules to ensure reliable and consistent data.

Project Objectives

- Establish a data quality contract with validation thresholds and escalation procedures.
